# Urlaubsplaner

Gemeinsame Urlaubswoche für die Freundesgruppe: Jede Person trägt ein, wann sie Urlaub nehmen könnte,
die Seite findet den Zeitraum, in dem die meisten gleichzeitig können.

- Website: https://niklas918.github.io/urlaubsplaner/
- Daten: Supabase-Tabelle `urlaub` (Adresse und öffentlicher Schlüssel stehen oben im Skript in `index.html`)
